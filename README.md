## 🎬 Project 1 — IMDb Sentiment Analysis  
**TensorFlow • Keras • LSTM • NLP**

A complete sentiment‑analysis pipeline built on the IMDb movie reviews dataset.

### **Key Features**

- Custom text preprocessing with `TextVectorization`  
- Word clouds and frequency analysis  
- Bidirectional LSTM classifier  
- Training/validation/test splits  
- Predictions on unseen text  
- Modular workflow for future models (GRU, CNN, BiLSTM)

### **Notebooks**

- `00_Text_Preprocessing.ipynb` — tokenization, vocabulary, word clouds  
- `01_Bidirectional_LSTM.ipynb` — main model  
- Optional: GRU, CNN, stacked LSTM architectures

## 🎭 Project 2 — Shakespearean Sonnet Generator  
**TensorFlow • LSTM • Character‑Level Modeling**

A character‑level language model trained on Shakespeare’s works, capable of generating text in Shakespearean style.

### **Key Features**

- Public‑domain Shakespeare dataset  
- Character‑level tokenization  
- LSTM‑based text generator  
- Temperature sampling  
- Logic for assembling a 14‑line sonnet (ABAB CDCD EFEF GG)

### **Notebooks**

- `00_Data_Exploration.ipynb` — dataset inspection & cleaning  
- `01_Character_Level_Model.ipynb` — model training  
- `02_Sonnet_Generator.ipynb` — text generation
